# Architecture Diagram Plan

Final diagrams are intentionally pending developer review.

- **C4 System Context:** show Nexus Commerce, its user roles, and external boundaries without implying operational integrations.
- **C4 Container:** show the planned gateway, services, frontend, stores, broker, identity provider, and observability components.
- **Sequence views:** later explain validated order, payment, inventory, and notification flows.

Diagrams must distinguish proposed from implemented elements, link to relevant ADRs, and be updated only after boundaries are reviewed.
