# ADR-003: Polyglot Programming

- **Status:** Proposed
- **Date:** 2026-11-25

## Context

The educational goal explicitly includes learning multiple languages through bounded services.

## Decision drivers

- Educational value and fit with the documented product scope.
- Clear ownership, interoperability, and local-development feasibility.
- An individual developer’s learning capacity and operational overhead.

## Alternatives

One standard language; limited two-language stack; planned polyglot stack.

## Decision

Use the documented language per service, subject to review before each implementation begins.

## Rationale

Creates deliberate, contextual language-learning opportunities.

## Positive consequences

- Increases cognitive load, duplicated tooling, and integration risk.

## Negative consequences

- Use learning checkpoints and compare operational cost after the first services.
