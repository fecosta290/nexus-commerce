# Product Roadmap

The roadmap is proposed and may change after refinement and architectural validation.

| Release | Objective |
|---|---|
| v0.1 | Project foundation |
| v0.2 | Product catalog |
| v0.3 | Inventory management |
| v0.4 | Identity and customer management |
| v0.5 | Order management |
| v0.6 | Simulated payment processing |
| v0.7 | Event-driven communication and notifications |
| v0.8 | Promotions and discounts |
| v0.9 | File and image processing |
| v0.10 | Product recommendations |
| v0.11 | Business analytics |
| v0.12 | Advanced observability and resilience |
| v1.0 | Integrated backend |
| v2.0 | Blazor web application |

Each release requires backlog refinement, acceptance evidence, documentation updates, and review against the [Definition of Done](../scrum/definition-of-done.md). Dates are intentionally not committed before capacity is measured.
