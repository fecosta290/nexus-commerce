# Definition of Done

An item is Done only when all applicable conditions are evidenced:

- Acceptance criteria and related business rules are satisfied.
- Developer-authored implementation is reviewed and follows agreed conventions.
- Appropriate developer-authored tests pass and relevant failure paths are covered.
- Contracts remain compatible or their change is explicitly managed.
- Security, observability, resilience, and data-ownership implications are reviewed.
- Documentation and ADRs are current.
- No secrets, generated artifacts, or unrelated changes are included.
- Local validation evidence is attached to the Pull Request.
- The related Issue and GitHub Project status are updated.

This definition evolves through retrospectives; exceptions must be explicit, not silent.
